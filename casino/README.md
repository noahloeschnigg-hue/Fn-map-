# Leck Eier

Ein privates Spaß-Casino mit Spielgeld im Stil der „Originals“. Startguthaben: 10.000 €, kein echtes Geld.

**Starten:** `casino/index.html` im Browser öffnen. Keine Installation nötig.

Spiele: Ice Fishing (Glücksrad mit Angel-Bonus), Dice, Limbo, Crash, Mines, Plinko, Keno, HiLo, Blackjack, Wheel, Dragon Tower, Roulette.

- Guthaben, Statistik und letzte Wetten werden im Browser (localStorage) gespeichert.
- „Auffüllen“ setzt das Guthaben wieder auf 10.000 €.
- Gewinnanimationen in Stufen (ab 2×, 10×, 50×, 250×) mit Blitz, Wackeln, Münzregen und Sound. Lautsprecher-Knopf oben schaltet den Ton ab.
- Die Spiele rechnen mit 1 % Hausvorteil (Roulette: europäisch, eine Null).
